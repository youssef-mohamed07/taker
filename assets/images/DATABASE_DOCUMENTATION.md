# 📘 التوثيق الشامل لقاعدة بيانات نظام التاجر (Tager POS & ERP Database)

---

## 📌 1. نظرة عامة (Overview)

قاعدة بيانات **`tager_db.sqlite`** هي قاعدة بيانات علائقية متقدمة مبنية بنظام **SQLite**، ومصممة خصيصاً لإدارة نقاط البيع (POS)، المخازن، المبيعات والمشتريات، الخزينة والورديات، وحسابات الشركاء للأنشطة التجارية ومحلات التجزئة والسوبرماركت.

* **اسم الملف:** `tager_db.sqlite`
* **المعمارية:** Relational 3NF + Autonomous SQL Triggers + Analytical Views + FTS5 Full-Text Search
* **اللغات المدعومة:** ثنائية اللغة (عربي / إنجليزي)
* **الأوزان والكسور:** دعم كامل للكسور العشرية (0.5، 0.25، 0.125، ميزان)

## 🤖 3. المشغلات الذكية التلقائية (SQL Triggers)

قاعدة البيانات مزودة بمشغلات تعمل تلقائياً مع كل حركة لضمان سلامة العمليات المحاسبية والمخزنية:

### 1. الخصم التلقائي عند البيع (`trg_after_sale_item_insert`)
* **الحدث:** عند إدراج صنف في جدول `invoice_items`.
* **الأثر:** يخصم الكمية فوراً من `products.current_quantity` ويضيف سطراً في `stock_movements` بنوع `SALE`.

### 2. استرجاع المخزن عند إلغاء بند (`trg_after_sale_item_delete`)
* **الحدث:** عند حذف بند من `invoice_items`.
* **الأثر:** يعيد الكمية لرصيد المنتج ويسجل حركة `SALE_CANCEL`.

### 3. زيادة المخزن وتحديث التكلفة عند الشراء (`trg_after_purchase_item_insert`)
* **الحدث:** عند تسجيل فاتورة شراء في `purchase_items`.
* **الأثر:** يزيد رصيد المخزن، يحدث `last_purchase_price`، ويحسب متوسط التكلفة المرجح `avg_purchase_price` وهامش الربح تلقائياً.

### 4. استرجاع البضاعة في مرتجع البيع (`trg_after_sales_return_insert`)
* **الحدث:** عند إدراج صنف في `sales_return_items`.
* **الأثر:** يعيد الكمية المرتجعة للمخزن ويسجل حركة `SALES_RETURN`.

### 5. خصم البضاعة في مرتجع الشراء (`trg_after_purchase_return_insert`)
* **الحدث:** عند إرجاع بضاعة لمورد في `purchase_return_items`.
* **الأثر:** يخصم الكمية من المخزن ويسجل حركة `PURCHASE_RETURN`.

### 6. تتبع تغير الأسعار آلياً (`trg_track_retail_price_change` & `purchase`)
* **الحدث:** عند تعديل سعر البيع أو الشراء في `products`.
* **الأثر:** يدرج سطراً آلياً في `product_price_history` يحتوي على السعر القديم، الجديد، والتوقيت.

### 7. تحديث رصيد الخزينة آلياً (`trg_update_treasury_on_transaction`)
* **الحدث:** عند تسجيل أي حركة في `treasury_transactions`.
* **الأثر:** يزيد رصيد الخزنة إذا كانت الحركة `INCOME` ويخصم إذا كانت `EXPENSE`.

## 📈 4. التقارير المدمجة (SQL Views Reference)

تقارير جاهزة للاستدعاء الفوري دون كتابة استعلامات معقدة:

### 1. بطاقة الصنف الكاملة (`v_product_details`)
* تجمع كافة تفاصيل المنتج: الكود، الاسم بالعربي والإنجليزي، الماركة، الفئة، الوحدة، الباركود الأساسي، الأسعار المتعددة، التكلفة، هامش الربح، حالة التوفر، وإجمالي قيمة المخزون.
```sql
SELECT * FROM v_product_details WHERE stock_status = 'متوفر';
```

### 2. تقرير النواقص وحد إعادة الطلب (`v_low_stock_alerts`)
* يعرض المنتجات التي وصلت أو نزلت عن الحد الأدنى (`min_quantity`)، مع حساب الكمية المطلوبة وتكلفة الشراء التقديرية.
```sql
SELECT * FROM v_low_stock_alerts;
```

### 3. تقييم رأس المال في المخزون (`v_inventory_valuation`)
* يحسب إجمالي قيمة البضاعة في المحل بسعر الشراء (رأس المال المجمد) وبسعر البيع وصافي الربح المتوقع ونسبة الربحية الإجمالية.
```sql
SELECT * FROM v_inventory_valuation;
```

### 4. ملخص المبيعات والأرباح اليومية (`v_daily_sales_summary`)
* ملخص لكل يوم: إجمالي الفواتير، الإيرادات، الخصومات، التكلفة (COGS)، وصافي الربح اليومي.
```sql
SELECT * FROM v_daily_sales_summary LIMIT 30;
```

### 5. الأصناف الأكثر مبيعاً (`v_top_selling_products`)
* ترتيب الأصناف تنازلياً حسب إجمالي الإيرادات والأرباح المحققة مع عدد مرات ظهورها في الفواتير.
```sql
SELECT * FROM v_top_selling_products LIMIT 10;
```

### 6. تقرير تفاصيل الوردية وتقفيل الكاشير (`v_shift_details`)
* يعرض كل وردية مع اسم الكاشير، رصيد الافتتاح، المبيعات النقدية، المصروفات، الرصيد المتوقع، الرصيد الفعلي، وحالة العجز/الزيادة.
```sql
SELECT * FROM v_shift_details;
```

### 7. كشف حساب العملاء والموردين (`v_customer_balances` & `v_supplier_balances`)
* كشف حساب فوري للأرصدة المستحقة وإجمالي المشتريات والمدفوعات.
```sql
SELECT * FROM v_customer_balances WHERE current_debt_balance > 0;
SELECT * FROM v_supplier_balances;
```

### 8. كشف حساب حقوق الشركاء والأرباح (`v_partner_equity_summary`)
* ملخص لكل شريك: نسبة الحصة، رأس المال الأساسي، إجمالي المسحوبات، إجمالي الأرباح الموزعة، وصافي حقوق الملكية.
```sql
SELECT * FROM v_partner_equity_summary;
```

## ⚡ 5. محرك البحث السريع بالنصوص الكاملة (FTS5)

تم تضمين محرك بحث **FTS5** فائق السرعة يدعم اللغة العربية والإنجليزية:

* **اسم الجدول الافتراضي:** `products_fts`
* **الحقول المفهرسة:** الاسم العربي، الاسم الإنجليزي، الكود الداخلي، اسم الماركة، اسم القسم، الباركود.
* **المزامنة:** يتم تحديث الفهرس لحظياً مع أي إضافة أو تعديل في جدول المنتجات عبر 3 مشغلات مزامنة.

### أمثلة للاستعلام:
```sql
-- بحث بكلمة عربية
SELECT * FROM products_fts WHERE products_fts MATCH 'جبنة' LIMIT 10;

-- بحث بكلمة إنجليزية
SELECT * FROM products_fts WHERE products_fts MATCH 'Pepsi' LIMIT 10;

-- بحث بماركة أو كود
SELECT * FROM products_fts WHERE products_fts MATCH 'جهينة' LIMIT 10;
```

## 💰 6. نظام التسعير والكسور والباركود

1. **الأسعار المتعددة لكل صنف:**
   * `purchase_price`: سعر الشراء والتكلفة.
   * `wholesale_price`: سعر الجملة للمحلات والتجار.
   * `semi_wholesale_price`: سعر نصف الجملة.
   * `retail_price`: سعر البيع للمستهلك.
   * `profit_margin`: هامش الربح المحسوب آلياً كنسبة مئوية.

2. **البيع بالكسور والأوزان:**
   * نوع البيانات في حقول الكميات هو `REAL`، وجميع الأصناف والوحدات مضبوطة بـ `allows_fraction = 1` مما يتيح بيع `0.5` (نصف)، `0.25` (ربع)، `0.125` (ثمن)، أو أوزان الميزان بالجرامات بكل مرونة.

3. **الباركود:**
   * جميع الأصناف الـ 216 مزودة بباركود قياسي **EAN-13** رسمي جاهز للمسح عبر قارئ الباركود أو الطباعة على الملصقات (Barcode Labels).

## 💻 7. دليل الربط البرمجي للمطورين (Developer Quickstart)

### Python:
```python
import sqlite3

conn = sqlite3.connect('tager_db.sqlite')
cursor = conn.cursor()

# استعلام تقرير النواقص
cursor.execute("SELECT name_ar, needed_quantity, estimated_reorder_cost FROM v_low_stock_alerts")
for row in cursor.fetchall():
    print(row)

# البحث السريع في المنتجات
cursor.execute("SELECT * FROM products_fts WHERE products_fts MATCH ? LIMIT 10", ('عصير',))
results = cursor.fetchall()
```

### Node.js / JavaScript:
```javascript
const Database = require('better-sqlite3');
const db = new Database('tager_db.sqlite');

// استعلام تقييم المخزون
const valuation = db.prepare('SELECT * FROM v_inventory_valuation').get();
console.log('إجمالي قيمة رأس مال البضاعة:', valuation.total_cost_value);

// إضافة صنف للفاتورة (سيتم خصم المخزن آلياً بواسطة الـ Trigger)
const insertItem = db.prepare(`
    INSERT INTO invoice_items (invoice_id, product_id, quantity, unit_price, discount, total, cost_price)
    VALUES (?, ?, ?, ?, ?, ?, ?)
`);
insertItem.run(1, 34, 1.5, 610.0, 0.0, 915.0, 592.0);
```

## 🔒 8. النسخ الاحتياطي والأمان (Backups & Maintenance)

* تم إنشاء نسخ احتياطية آمنة في نفس المجلد:
  * `tager_db.backup.sqlite` (النسخة الأولية)
  * `tager_db.backup2.sqlite` (نسخة بعد الماركات والأكواد)
  * `tager_db.backup3.sqlite` (نسخة قبل التريجرز والفيوز)
* تم تطبيق أوامر **`ANALYZE`** و **`VACUUM`** لضغط الملف وضمان أعلى سرعة استعلامات في شجرة بيانات SQLite.
